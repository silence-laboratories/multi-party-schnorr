# Report a Vulnerability

If you discover a security vulnerability in this artifact during review,
please follow responsible disclosure practices:

- Contact the anonymous submission authors through the venue’s designated
  artifact / anonymous communication channel (do not open a public issue).
- **Do not** open a public issue in any related repository until the
  disclosure process has been completed.

Kindly refer to the [OWASP Vulnerability Disclosure Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Vulnerability_Disclosure_Cheat_Sheet.html) as a guideline.
